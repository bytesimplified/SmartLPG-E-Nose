# SmartLPG-E-Nose

An **experimental** ESP32-based electronic-nose prototype for exploring LPG-responsive sensor signals in a home-kitchen context.

> **Not a certified gas alarm.** This student prototype is not suitable as the sole means of detecting a gas leak. Install and maintain an independent certified LPG detector. Do not intentionally release LPG indoors to test this device.

Project firmware, setup instructions, and validation tools are being introduced via pull requests.
